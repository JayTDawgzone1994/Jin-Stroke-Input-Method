# 0002 — Conway 索引與修正管線

採用日期：2026-09-17。

1. 字庫解析／修正放在獨立 dictionary_build 靜態庫，執行期 dictionary 不連結 Conway parser。
2. 同時固定原始 Conway 與展開參考表；每次建置先全量比對再篩選，防止錯解反向引用或漏字。
3. traditional 使用上游分類，明確保留未標記字。不把名稱誤當成台灣正字認證；個別地區政策放覆寫層。
4. 二進位格式固定寬度與位元組序，保留內嵌來源／授權，CRC32 驗損壞；輸出包保存完整來源快照。補字檔以有順序的獨立層維護。
5. 先採 immutable owned records＋排序表二分搜尋，不實作平台 memory mapping。這是對先前評估的簡化：資料約 1.5 MiB，先降低平台與格式複雜度；未來效能／記憶體量測需要時再換 backend。
6. 不在本階段匯入香港字頻或宣稱台灣筆順全部核對；順位欄位保留未設定值，讓後續排序策略獨立處理。
7. 輸出使用新版本目錄與 staging，拒絕覆寫，避免更新時破壞已存在的字庫。
