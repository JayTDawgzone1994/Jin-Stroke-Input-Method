# 0003 — 純核心狀態機與提交確認

2026-09-17 採用。

1. Session 以不可變字庫和設定副本工作，每個輸入 context 獨立且不可複製；不引入 Windows 物件或背景寫檔。
2. 固定排序為 exact 優先、frequency_score 降冪、碼點升冪，保證同樣資料與輸入得到同樣候選；後續台灣排序可填入 score 或更換明確排序策略。
3. 選字只產生 CommitRequest，待宿主成功確認才清空組字；失敗保留狀態。所有選字與提交事件帶 revision，平台層另核對 context id。
4. 查無字保留使用者筆劃；正常錯誤不毀掉上一個可見狀態。組字結束前拒絕修改設定。
5. 個人學習尚未實作，因此明確拒絕要求開啟該設定，不默默忽略使用者意圖。
6. 互動 console 是獨立測試宿主，只模擬提交；沒有透過貼上或 SendInput 假裝 Windows 輸入法。
