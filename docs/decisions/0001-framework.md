# 0001 — 純 C++ 模組化框架

狀態：本次採用；2026-09-16。

## 背景

使用者要求先完成開發軟體框架，並統一 C++ 以方便維護。本次不是開發能安裝使用的 IME。

## 決定

- C++20、CMake 3.25+、CTest；沒有 Python 或第三方套件的建置依賴。
- domain／engine 為靜態庫；尚未實作的 backend 用 interface target 表達邊界，避免空 DLL 冒充完成品。
- MSVC 作為正式 Windows 工具鏈；以現有 MinGW 先驗證共用程式。兩者驗證結果分開記錄。
- 測試使用小型 C++ 執行檔，足夠驗證當前契約；測試量增加再評估成熟測試函式庫。
- 不預先凍結尚未確認的按鍵配置；設定與筆劃分離。
- 不加入常駐服務、IPC、資料庫或動態外掛載入器。

## 影響

可先獨立編譯與測試核心，且不需 Windows SDK。未來 TSF／UI 加入後仍需實際 MSVC、SDK 與宿主測試；本次成功不代表平台相容性已驗證。設定／安裝程式先保留目錄與責任，不建立無作用的可執行檔。
