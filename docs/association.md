# 逐字模式的聯想字

0.8.0 開發版新增「逐字模式顯示聯想字」，預設關閉。在設定的「選字習慣」關閉連續輸入、開啟聯想字，按「套用變更」。連續輸入使用整段組字；逐字聯想每次選字立即送出，不會回頭修改文字，也沒有組字底線。

## 操作

- 正常輸入筆畫並選一字；成功送出後，詞庫有接續字才顯示聯想窗。
- 用 1～9 選下一字，立即送出並繼續查聯想字；反轉選字設定同樣適用。
- Page Up／Down 翻頁；無效數字不輸出。
- 筆畫鍵改為正常查下一字，可以把自行輸入的字接到目前上下文。
- Esc 關閉聯想；空白、Enter、左右方向鍵、Backspace、符號與快捷鍵交給原程式，並清除聯想上下文。正常筆畫候選的空白／Enter 選首字、左右翻頁仍保留。
- 游標或文字變動、切換輸入框、失焦、切換輸入法後清除聯想。Shift 英文也會中止聯想。

## 查詢

固定詞庫沿用 `dictionary/phrases/phrases.pidx`，另合併本機個人詞與接字次數，見 [個人詞庫](personal-words.md)。沒有新下載或其他引擎依賴。載入前綴樹後，以一次反向遍歷快取各節點的最高詞分數；同一個接續字可出現在多個詞，取其最高分。分數降冪，同分按 Unicode 排序；零分詞不提供聯想。

只保存此輸入法成功送出的最近七個 Unicode 碼點，不讀取應用程式現有文件。查詢優先採用有接續候選的最長相符後綴，沒有時逐步退回較短後綴。例如「你好」有接續詞就先使用該前綴，不被「好」的其他高分詞蓋過；完整詞結束後仍可用其末字接其他詞。

前綴查詢與逐字提交分開：`Association` 管理成功提交的短上下文；`PhraseIndex::next` 產生候選；`Session::suggest` 沿用分頁、revision 與提交確認。`SessionSnapshot::association_prefix` 用於候選窗與 UILess 描述，沒有筆畫輸入或 TSF composition。

## Windows 提交

- 初次選字及每個聯想字都使用原本同步優先／非同步退回的文字提交。成功插入後才擴展聯想與本地學習；失敗保留原聯想供重試。
- 只有能把游標可靠移到插入字尾並保存 TSF range 時才開啟聯想窗；游標設定失敗不重複插字。
- 接續提交在實際取得寫入鎖後比較當前選取範圍與保存的字尾位置；位置不符時取消並關閉聯想，避免延後工作插到新位置。
- 外部編輯、取消與失焦會清除候選、上下文及過期回呼。非同步尚未完成時，重複數字選字不會選到下一個字。
- UILess 的候選、宿主分頁與顯示協商繼續使用；原生候選框標題顯示「聯想」，跟隨既有深淺色與圓角。

## 設定

SL4 共 32 bytes：沿用前 30 bytes 的鍵位與反轉配置，第 31 byte 為連續開關，第 32 byte 為聯想開關（各為 0／1）。讀取 SL1／SL2／SL3 保留舊設定，聯想預設關閉；寫入 SL4。檔案超長或旗標不合法會拒絕。

連續模式開啟時，設定介面的聯想開關自動關閉並停用；切回逐字後仍保持關閉，需自行開啟。SL4 寫入時也會清除與連續模式衝突的聯想旗標；讀取先前同時啟用兩者的設定時，以連續模式為準並關閉聯想。設定與 DLL 必須一起更新。正在筆畫組字／送字時保留原設定；只有聯想窗時可以在下一鍵套用新模式並清除舊聯想。

## 驗證與限制

核心測試涵蓋最高分合併、最長後綴、完整詞串接、零分過濾、Unicode、歷史上限、宿主分頁、提交失敗與學習停用。TSF 模擬宿主涵蓋直接送字、連續聯想、失敗重試、反轉選字、失焦／外部編輯、非同步游標移動及游標設定失敗。WinUI 隔離測試檢查自動關閉聯想、切回逐字保持關閉，以及模式保存。TSF 模擬宿主也驗證原生聯想候選視窗確實顯示。

固定詞庫與本機個人詞共同決定聯想內容；支援依前文的接字學習，沒有句子語意分析或跨輸入框上下文。宿主的真實聯想窗呈現與相容性仍需用新安裝版實際驗收。
