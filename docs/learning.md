# 本地常用字學習

開發版已完成；尚未重新打包或安裝。新酷音固定分數與個人資料分開保存。

## 使用方式

設定視窗新增「學習常用字」（預設開啟）及「清除學習紀錄…」。開關要按「套用」才儲存；關閉時停止使用個人加分與新增紀錄，但保留既有資料。重新開啟可繼續使用。清除按鈕經確認後立即清空，不改按鍵配置或新酷音字頻。

只記錄成功輸出的候選字。取消、輸出失敗、Shift 英文不計次；左右手配置及不同筆順共用同一個字的統計。學習資料約每 500ms 同步，排序從下一次組字生效；正在選字的候選不重新排列。

排序仍為完整吻合優先，同一組內比較「新酷音分數＋個人加分」，同分按碼點。

```text
個人加分 = floor(60000 × 使用次數 / (使用次數 + 10))
```

| 累計次數 | 個人加分 |
| --- | ---: |
| 0 | 0 |
| 1 | 5,454 |
| 5 | 20,000 |
| 20 | 40,000 |

上限低於 60,000；每字計數最多 1,000,000，避免無限增長。比較使用 uint64，原始字頻 uint32 不被改寫，也不會加法溢位。這是第一版強度，之後可依實際試用調整；並非選過一次就固定排第一。最後使用時間只保存，暫不作衰減或排序。

## 資料與同步

- 位置：目前 Windows 使用者的 `%LOCALAPPDATA%\StrokeIME\learning.dat`；安裝程式不覆蓋或刪除這個位置。
- 保存單字碼點、次數、最後使用時間，不保存整句、應用程式名稱或輸入順序；不傳送網路資料。
- 以 `learning.dat.lock` 的獨占檔案 handle 協調不同程序。遇到鎖忙立即返回，timer 下次重試，不等待鎖。
- 在鎖內讀取最新資料，合併尚未確認寫入的增量，暫存檔完整寫入並 flush 後原子替換正式檔。失敗保留原檔及待寫批次。
- 清除、停用、重新啟用均產生新 generation GUID。舊程序帶舊 generation 的批次直接丟棄，避免清除後復活，或停用期間的事件延後混入。
- 清除不刪除檔案，而是寫入空統計及新的識別碼；這個識別碼是跨程序丟棄舊紀錄所必需。
- 格式 `STROKE-LEARNING-1`；最多 4 MiB／10 萬項，驗證數字範圍、碼點及重複項。

## 程式邊界

`Session::configure(dictionary, config, learned)` 只允許 idle 時更新個人快照。`complete_commit` 只有在成功、學習啟用且 acknowledgement 有效時回傳 `Update.learned_character`；重複回報不會再次發事件。

Windows adapter 在按鍵回呼只更新記憶體。既有 500ms 訊息視窗 timer 負責同步磁碟與其他程序；下次 idle 時套用快照。此版不是背景執行緒，磁碟 I/O 在 timer 上執行。正常停用輸入法時會嘗試送出最後批次。

初次無法讀取個人資料時仍能使用一般字頻排序；後續讀取失敗保留最後有效快照。儲存失敗不改變已成功的文字輸出，不讓應用程式再輸出一次。損壞檔案不自動覆寫；設定視窗的明確清除操作可以重建它。

限制：程序被強制終止、斷電，或停用時恰好無法取得寫入鎖，可能失去尚未同步的最後一批紀錄。各程序的設定與清除狀態需等待自己的訊息 timer 同步；忙碌或暫停的程序可能延後。

## 驗證

- x64／x86 Release 各 17 項 CTest 通過。
- 學習事件：成功才計一次、失敗／取消／停用不計、候選快照固定、加分遞減有上限。
- 儲存：两個獨立程序同時累計共 40 次，結果不遺失；重開讀取、鎖競爭、原子替換失敗與重試、清除 generation、防舊資料復活、損壞拒絕及明確重建。
- 透過 computer-use 檢查開發版設定視窗：開關、清除、套用等控制項完整顯示。未在現用系統輸入法上進行本輪真人打字測試。
