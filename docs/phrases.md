# 連續輸入詞庫

採用固定快照 `libchewing-data/tsi.csv` 的詞語與優先分數，移除注音；本專案沒有連結新酷音引擎。原始資料與衍生索引依 LGPL-2.1-or-later 提供，自行撰寫的轉換器與排序程式維持 MIT。

## 資料整理

- 保留 2～8 個 Unicode 碼點的詞語，所有字必須存在於指定的 Conway 筆畫索引。
- 同詞不同讀音合併，取最高分；分數越大越優先。這是上游調整過的優先值，不是原始出現次數或機率。
- 目前快照 `c44e81aef24b06f1509f19e1be54c99812d0c43f`：160,458 筆資料，排除 26,073 筆單字與 16 筆超長詞，合併 5,412 筆重複讀音，得到 **128,957 個詞語**。沒有詞語因缺字被排除。
- 現用索引 1,501,020 bytes；詞語按 Unicode 排序，相同來源與筆畫索引可重現相同 bytes。

從專案根目錄重建到不存在的新目錄：

```powershell
$builder = './out/build/package-x64/tools/dict_builder/Release/stroke_dict_builder.exe'
& $builder phrases --source data/upstream/libchewing-data --index data/generated/conway-v2.0.2-traditional/dictionary.sidx --output out/phrases-new
```

整包輸出包含 `phrases.pidx`、`NOTICE.txt`、`report.tsv` 與 `sources/`。sources 保留未修改的 tsi.csv、完整 LGPL、固定 commit 的來源 ZIP 與 provenance。打包時重新生成對應實際筆畫字庫的詞庫，連同 `dictionary/frequency/converter-source.zip` 提供對應轉換程式。

## 索引格式

只支援目前格式，不保留舊版詞庫格式的轉換路徑。`phrases.pidx` 是 UTF-8，LF 結尾：

```text
STROKE-PHRASES-1
筆畫索引的 data_version
上游 40 位 commit
下方所有資料列的 CRC32（十進位）
詞語<TAB>uint32 優先分數
...
```

詞語嚴格遞增且不重複。載入時檢查 UTF-8、2～8 碼點、分數範圍、版本、中繼資料與 CRC32；限制 16 MiB、200,000 詞。載入後使用不可變的前綴樹查詢。

TSF 從 DLL 旁 `dictionary/phrases/phrases.pidx` 載入。筆畫 data_version 必須完全吻合；遺失、損壞或版本不符則回退單字排序，不阻止輸入法啟用。更新 DLL 時同包覆蓋字庫。

## 如何選詞

連續模式每次按空白接受字、數字選字或刪草稿字後，重新計算整段尚未送出的字串。每字保存原筆畫及當時排序前 64 個候選；使用者用數字、開啟候選後確認或翻頁確認過的字會鎖定，只允許其既選字。

前綴樹與各位置的候選交集找出可用詞語，動態規劃選擇最高總分的非重疊組合，其餘位置用單字第一候選。詞語的加分為 `ln(1 + 詞分數) + 2 × (詞長 − 1)`，各字扣除 `2 × ln(1 + 單字候選順位)`（順位從 0 開始）。分數為 0 的詞不加分。這是可調整的啟發式排序，不做句子語意分析。

新的字可能讓先前自動選字改變，例如原先暫選「女」「子」，在有「你好」的詞庫與相符候選時改為「你好」。手動指定「女」則保持該字。左右移動後按下開啟候選，第一候選會對齊草稿中目前的字。最後按 Enter 才送出整段、記錄實際輸出字的本地學習。

## 限制與維護

- 未完成、尚未確認選字時顯示原始筆畫；接受漢字後才參與選詞。
- 單段上限 256 字、每字 64 個自動候選、每個起點最多遍歷 8,192 個前綴節點。非常模糊的筆畫可能因此漏掉適合的詞，仍可開候選手動選字。
- 支援句內多個相鄰詞組；沒有詞語學習、詞組候選選單或跨次輸入的上下文。
- 本地字頻會影響初始候選順位；已送出文字不會回頭修改。任何宿主提交失敗都保留草稿與手動鎖定。
- 新增／移除筆畫字或換上游快照後必須重新產生詞庫，保留各來源與授權；不要直接編輯 pidx。

## 驗證

`engine.phrases` 涵蓋詞分數、重疊分詞、手動鎖定、刪字回退、補充平面字、提交失敗及檔案損壞。`dictionary.phrase_source` 驗證真實來源、重現性、最大分數合併、長度／缺字過濾、拒絕負分與原始資料保存。`windows.tsf_host` 驗證詞組的非同步更新、重開候選、手動改字、Enter 提交及損壞詞庫回退。實際宿主相容性仍需以安裝的新 DLL 驗收。
