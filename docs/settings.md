# 按鍵配置與 WinUI 3 設定介面

新版開始功能表 → 錦筆劃輸入法 → 錦筆畫輸入法設定。使用 C++/WinRT 與 WinUI 3，不需管理員權限；外觀跟隨 Windows 深淺色。

## 鍵盤配置

上方選擇「標準／傳統／自訂」，下方顯示 ANSI 主打字區，不畫功能鍵列、編輯區、方向鍵或數字小鍵盤，也不區分左右手。

| 按鍵 | 標準 | 傳統 |
|---|---|---|
| Q、U | 點 | 橫 |
| W、I | 折 | 豎 |
| E、O | 萬用 | 撇 |
| A、J | 橫 | 點 |
| S、K | 豎 | 折 |
| D、L | 撇 | 萬用 |

點擊 A～Z 會彈出筆畫選單，可選五種筆畫、任意筆畫或取消綁定。保留用途的其他鍵不可點選。
每個字母只能指定一種筆畫，同一筆畫可以配置任意數量的字母，不限制兩組。

修改預設配置時，以當前預設為基礎建立自訂草稿，上方立即切成「自訂」。單純打開選單、取消選單或選擇原有綁定，不會變更模式。切換到預設再切回自訂，保留先前自訂內容。編輯另一個預設則以該預設覆蓋自訂草稿；按「套用變更」才寫入磁碟。

未儲存就關閉會詢問。試打區使用當前草稿，只預覽筆畫，不查候選字；未綁定按鍵顯示「·」。

## 維護邊界

- `src/windows/storage/layout.hpp`：純 C++ 配置模型、預設、驗證、固定 30-byte SL2 格式（26 個字母各存一個 0～6 的筆畫值）；模式與自訂配置一起保存。
- `layout_store.cpp`：Windows 使用者 LocalAppData/StrokeIME/layout.dat。先寫同目錄暫存檔並 FlushFileBuffers，再 MoveFileEx 原子替換；失敗保留原檔。x86/x64 共用同一份。
- `apps/settings/winui`：WinUI 3 圓角卡片、完整打字區鍵盤、即時驗證、試打與儲存提示。以執行緒內按鍵擷取避免輸入法攔截設定字母；內容可捲動，套用按鈕固定在底部。建置與部署見 [winui-settings-build.md](winui-settings-build.md)。
- TSF service：每個啟用的服務透過 message-only window 的 500ms 計時器讀取最新設定，鍵盤回呼不存取設定檔。快取在 idle 才套用，不改動進行中的筆劃或待提交候選。停用時清理計時器和視窗。
- 缺檔採標準模式；損壞／無法讀取時保留最近可用配置，首次啟用則採標準。設定視窗會提示讀取失敗。
- 輸入法更新仍需重開原本載入舊 DLL 的應用程式；0.3.0 載入之後，修改配置不需重啟。
- 不支援操作鍵改綁、六碼模式、詞組；Shift 英文與 Caps Lock 規則不受布局影響。

目前使用完整設定的小檔案輪詢，未加入跨程序通知或設定同步雲端。多個設定視窗同時套用時，以最後一次成功儲存為準。

## 本地學習

開發版新增「學習常用字」開關及「清除學習紀錄…」。開關變更需套用；停用保留紀錄。清除經確認後立即執行。資料在 LocalAppData 的 learning.dat，與 layout.dat 分開。完整行為及限制見 [learning.md](learning.md)。


## 反轉選字鍵順序

開發版提供切換開關「反轉選字鍵順序（9 → 1，首字按 9）」，預設關閉。按套用後，下一次組字生效。第一至第九個候選分別標示／使用 9、8、7、6、5、4、3、2、1；字頻與個人學習排序不變。每一頁都使用相同對應；只有三個候選時為 9、8、7，其餘數字不選字。空白／Enter 仍選第一字，PgUp／PgDn 仍翻頁。恢復預設會關閉反轉。

選字標示與輸入共用 storage/selection.hpp；使用目前組字的 applied_layout，避免設定同步時標示和按鍵不一致。layout.dat 使用 SL2，第 4 byte 是模式（0、1、2）加反轉旗標（+3）。讀取已安裝版本的 SL1 時，將原有 12 個按鍵欄位轉成字母對應表，保留模式與反轉設定；只有使用者按套用時才寫成 SL2。舊版輸入法無法讀取 SL2，因此設定程式與 TSF DLL 必須一併更新；更新後重開仍載入舊 DLL 的應用程式。
